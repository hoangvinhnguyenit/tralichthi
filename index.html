Danh mục Môn học / Mô-đun

Mã môn = mã lớp học phần bỏ 2 số cuối (VD: lớp MH201263601 thuộc môn MH2012636). Môn mới trong dữ liệu thi sẽ tự được thêm vào danh mục.

Mẹo Import chính xác 100%:

• Với File Excel (.xlsx): Hệ thống tự động quét tiêu đề cột (Mã lớp, Môn học, Ngày thi, Giờ, Phòng, CB Coi thi 1, 2, GK1, GK2...).

• Với File PDF scan ảnh: Nếu file PDF là bản scan con dấu đỏ (không có lớp văn bản), hệ thống đã tích hợp sẵn bộ dữ liệu trích xuất OCR từ 2 file PDF của trường hoặc bạn có thể dán bảng trực tiếp.
